What it does

Everything you need for sprites, and nothing you don't.

Draw

Pencil, eraser, flood fill, line, rectangle, ellipse, select & move, eyedropper. Mirror drawing across either axis, so a symmetrical character takes half the strokes.

Layers & frames

Add, reorder and merge layers. Animate on a timeline with onion skinning — previous frame in red, next in blue — and adjustable fps.

Palettes that swap

Game Boy DMG and Pocket, GBC, PICO-8, NES, Sweetie 16, CGA, Endesga 32. Switching remaps your art to the nearest colour, so you can redraw a sprite in a different mood without starting over.

Export anywhere

PNG, spritesheet, animated GIF, SVG, a data-URI <img>, or the whole sprite as one CSS box-shadow with zero image requests.

For agents

Let a model draw into the same library.

A language model is good at describing a picture as rows of characters, and pixel art is rows of characters. So the main authoring tool takes ASCII, and the preview tool hands back a real PNG the agent can look at. Draw something with an agent, then open it here and fix it by hand — or the other way round. 

claude mcp add pixelart -- node mcp/server.js

draw_ascii  name="coin"
            key={"K":0,"d":1,"m":2,"l":3}
            rows=["..KKKK..",
                  ".KmmllK.",
                  "KmmllmmK",
                  "KmlldmmK",
                  ".KmmmmK.",
                  "..KKKK.."]
